# Política de Segurança

se algum jogo danificar seu dispositivo, não somos responsáveis por isso, só vamos banir ele da loja!

Lista de Versões que Suportam Atualizações de Segurança:

| ------- | ------------------ |
| 4.1.x   | :white_check_mark: |
